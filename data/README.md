# Data

The training data is not in the repository (52 MB). Download the **Phishing Email Detection** dataset
(`Phishing_Email.csv`, columns `Email Text` and `Email Type`, about 18,600 emails: 11,322 "Safe Email" and
7,312 "Phishing Email") from Kaggle and place it here as `data/Phishing_Email.csv`.

Or point to it elsewhere: `DATA_CSV=/path/to/Phishing_Email.csv`.
